# История изменений

## 0.5.2 — 2026-10-03

Совместимость с Anime Shop Simulator 1.0.7.

- Исправлено создание страницы статистики в Anime Shop Simulator 1.0.7 после удаления поля _levelText из игрового терминала.
- Заголовок и подзаголовок сдвинуты, чтобы освободить место для новой кнопки с домиком. Обновлены фон и акцентные цвета страницы.
- Страница использует исправленную навигацию и плитку терминала из WolfCore 0.2.6.

Сборка и короткая игровая проверка основных сценариев прошли успешно. Для модулей используйте WolfCore 0.2.6.
