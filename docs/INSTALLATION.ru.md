# Установка статистики товаров

[Вернуться на главную страницу](../README.md)

## Требования

- Anime Shop Simulator для Windows;
- [MelonLoader](https://github.com/LavaGang/MelonLoader) `0.7.3`;
- [WolfCore](https://github.com/Midfr0st/AnimeShopSimulator-WolfCore) `0.2.5` или совместимая версия.

## Установка

1. Закройте игру.
2. Установите MelonLoader и один раз запустите игру.
3. Скачайте `WolfCore.dll` из [выпуска WolfCore](https://github.com/Midfr0st/AnimeShopSimulator-WolfCore/releases/latest).
4. Скачайте `WolfProductStatistics.dll` из [выпуска мода](https://github.com/Midfr0st/AnimeShopSimulator-ProductStatistics/releases/latest).
5. Поместите обе DLL непосредственно в `Anime Shop Simulator\Mods`.

## Проверка

Откройте `Esc` → `Моды` и убедитесь, что `Статистика товаров` включена. Затем откройте терминал управления магазином: плитка `Статистика` появится среди доступных страниц.

Если суммарно установлено больше шести терминальных плиток, WolfCore разместит дополнительные на следующем экране.

## Обновление и удаление

Заменяйте DLL только при закрытой игре. Удаление `Mods\WolfProductStatistics.dll` отключает мод. Файлы из `UserData` можно оставить для будущего обновления или удалить для полного сброса накопленной статистики.
